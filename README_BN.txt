ALL STOCK — UPDATED WEBSITE PACKAGE

Included:
- index.html
- style.css
- script.js

IMPORTANT LIMITS
This is a static GitHub Pages website. It displays a service catalog, sample prices and sample stock counts. It does not provide a database, admin dashboard, live shared inventory, automatic payment verification, or payment processing.

SAFE CONFIGURATION
This template is for legitimate digital setup/support services. It is not configured to sell or transfer personal social-media accounts, passwords, OTPs, or recovery codes.

BEFORE PUBLISHING
1. Open script.js in an editor.
2. Replace YOUR_TELEGRAM_USERNAME with your Telegram username (without @).
3. Replace YOUR_WHATSAPP_NUMBER with your WhatsApp number in international digits only (Bangladesh example format: 8801XXXXXXXXX).
4. Edit the products array in script.js to set your real service names, prices (BDT), and available quantities.
5. In index.html, replace ADD_NUMBER with your verified business payment instructions for bKash, Nagad, and Rocket. Use a legitimate merchant/business payment number and clearly state payment type.
6. Save all files and upload/overwrite index.html, style.css, and script.js in the root of your GitHub repository.
7. Commit changes and wait for GitHub Pages to redeploy.

ORDER AND STOCK NOTES
The Order button opens Telegram's share flow with the order details; the customer must send the message manually. The configured support links are used for the support buttons. Static GitHub Pages cannot securely decrement stock after an order. For real-time stock and verified checkout, you need a secure backend and an approved payment gateway integration.

Never ask customers to send passwords, OTPs, PINs, or recovery codes.
